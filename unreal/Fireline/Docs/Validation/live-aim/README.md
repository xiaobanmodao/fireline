# M4 准备／瞄准：原图驱动的独立候选

本阶段完成可操作的第三人称 Relaxed／Ready／Aiming 候选，仍待用户观感评价。范围限 M4 平地准备、瞄准与移动组合；换弹、开火、第一人称机瞄／Coyote 镜头尚未接入此入口。原游戏基线、第一人称、正式0.1.10和旧入口保留。

## 体验入口

访达中双击桌面「火力对决／**测试版·M4准备与瞄准.app**」。这是共享独立工程的启动入口，不是冻结的历史二进制。

- 右键按住瞄准，松开回准备，随后按原图逻辑回到放松携枪；支持反复打断。
- WASD移动，Shift慢跑；瞄准时回走速。Q/E改变身体朝向，↑/↓调整俯仰（±30°）。
- 鼠标自由环绕，1–4切换四面观察，5切换原版ALS参照，R回起点并复位俯仰。
- 重点检查：移动中抬枪、快速点按右键、松开回落、侧移瞄准与转身。

## 实施依据

直接驱动原 `AB_Als_Rifle` 状态机，读取 Relaxed、Ready、Aiming 的真实权重，不把输入事件当作动画已经结束。保留原状态时间、连续图实例和下半身相位。原 Relaxed Jog 节点在其他状态会停更，故只按 Relaxed 权重使用；旧走跑入口仍保留其原断言。

枪械方向从原 `hand_r` 附着旋转注册。双掌跨度用于不同握持的配准，不能替代枪械附着轴；早期自由拟合虽通过几何检查，却把准备姿态变成抬高枪口，已经否决。完整瞄准时只约束共同手／枪组件的准星轴线和上向。

适配保留现有 Ryan/DJ 派生比例、真实网格绑定、蒙皮、手指及双手相对M4的接触。共同组件注册来自右手源位置；完整肩臂以固定长度求解，DJ_forearm仍是蒙皮辅助。此注册有约10厘米的位置差异，不是逐骨原样复制，也不能称为微小修补。

静止与移动的源姿态存在不同肘部净空。额外移动配准由原图 `PoseMoving × Aiming权重` 驱动，先求原肘部弯曲圆弧，再限制该额外修正的腕部转折至44.5°；不会独立移动手、伸长骨骼或压弯小臂。44.5°是本项目审查约束，不是人体通用活动极限。

## 实际检查

30／60／120 Hz分别记录1711／3421／6841帧，全部检查最终蒙皮顶点与完整候选三角面：0无效姿态、0所测胸部包络穿插、肢段长度／握持误差均小于0.002厘米；准星方向误差小于0.1°。60 Hz使用Metal原生窗口与28张四向截图，30／120 Hz为NullRHI原生姿态复算，不能当作对应帧率的视频观感验收。

检查覆盖静止瞄准/回落、八方向走跑切瞄准、连续打断、±30°俯仰及转身侧移。旧Stage2原生4153帧隔离回归通过，1252个既有资源校验未变。详细值见 audit-30/60/120.json；原生记录与截图留在 manifest.json 对应的本机 Saved 路径。

早期测试曾越过参考地图台阶，后续路线已限制为平地并断言胶囊高度。顶点和面心检查会漏掉三角边穿入胸部，最终改为所有测试帧率都执行真实三角裁剪；历史失败、低帧率回归失败及无腕限制的移动修正失败均保留，见 failed-trials.json。

## 仍未验收

这里只检查胸部凸包与指定臂/枪表面，不是全角色所有部件的碰撞证明。肩甲缝、精确贴腮／枪托肩窝、严格零脚滑和所有输入组合仍未获视觉验收。原图由跑姿快速举枪时仍有较急的手部移动，不能把来源成熟或数值通过等同于完全自然。第一人称射击体验、武器操作、蹲跳滑铲和其他武器另行处理。

下一项仍是完整第三人称M4换弹：先确定源全身动作、弹匣脱手/落地/新弹匣握持/入位/拉栓的接触阶段，保留现有第一人称与弹匣入位刷新弹药、打断及0.85倍换弹规则。第3阶段尚未整体完成。

## 复现

`python3 scripts/prepare_live_carry_study.py --aim --build --install` 加载版本控制中的 aim-fit.json。校准辅助脚本依赖本机保留的失败/源姿态追踪，普通运行不重新拟合；第三方二进制与原始动画未上传仓库。

原生运行加 `-LiveCarryAudit -StudyFPS=60 -StudyRun=<新的标签>` 捕获；再用 AnimationPython 环境运行 `scripts/audit_live_carry.py --aim --directory <捕获目录> --fps 60`。30/120同理；已有证据目录会拒绝覆盖。
