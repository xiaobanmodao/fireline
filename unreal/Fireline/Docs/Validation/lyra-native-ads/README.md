## 漏掉的关键：最终表面不等于原动画轨道

`SKM_Manny`自带`ABP_Manny_PostProcess`，包含14个不同的PoseDriver及`CR_Mannequin_Procedural`。锁骨驱动肩胛、胸侧等修正骨；上臂/前臂分别驱动体积和肌肉辅助骨；手骨驱动内外腕修正骨。这些修正骨对蒙皮有实际权重，不能只读取主要骨骼角度后宣布“复刻原版”。

同时间的两组实际原生回放，只改变后处理开/关：肩臂主导区域5302个渲染顶点，四个采样帧中约2558–2562点的表面变化超过1cm，最大约4.47cm。辅助骨的旋转可能超过100°，它们是表面修正控制，不代表人体关节被扭到该角度。

离线`AnimPoseEvaluationOptions`默认读取Raw，本次还关闭了重定向；与运行时无后处理回放仍有最大约0.158cm/0.142°差异。这不是后处理量。后处理量和P切换验收均改用两个**原生**输出对比，没有放宽门槛掩盖差异。P所调用的实际切换函数在第29/59帧关闭/恢复，129帧与对应原生开/关对照完全一致（四元数误差约1e-14°）。

原生四面已查看：右肘位于较低位置，胸背、锁骨、上臂和前臂共同支撑原枪。也不能称源片“零穿模”：四个样本里头颈/枪交叉为0，完整脊柱/锁骨主导面与枪仍有210–224对交叉。这里的三角面对数不是严重程度指标，不可与不同拓扑角色直接排名；局部接触、软组织压靠和可见轮廓还需结合画面判断。本轮未运行完整Lyra游戏AnimBP、镜头/瞄准偏移或不同LOD条件，未确定解剖眼点。
