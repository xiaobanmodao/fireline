## 发现和修复

**鞋跟穿地。** 原固定片段地面偏移在新输入相位下最深-1.99cm。第一次刚性脚骨点校正仍失败，最深-2.90cm。检查实际权重确认，部分鞋跟同时受Foot和LowerLeg影响（例如36751/28784），刚性脚点不能代表最终蒙皮。当前使用完整靴面影响骨计算实际鞋底高度，依供体接触曲线做有界高度求根，再按固定腿长与源膝盖平面求解；摆脚只防穿地，接触段允许贴地。不改权重、不整体抬高人物、不伸缩腿。两个失败输出保留在本机`initial-audit-60`、`rigid-sole-failed-60`。

**右前臂边缘进入胸廓。** 顶点均在胸廓外，但60Hz第128–134帧同一个右前臂三角面边缘相交，面积最大0.251cm²。针对保留的未修正实时捕获，计算一维恒定肘平面注册：绕肩到手轴增加5.6953125°，保持双腕、枪械和臂长不变。数值来自实际三角面间隙，不逐帧挪手或突然切修正。标定脚本为`calibrate_live_carry_clearance.py`，准备脚本校验目标绑定哈希。最终60Hz全661帧相交为0。

## 验证

数据见本目录三档`audit`、`reference-parity`和`manifest`。

- UE5.8 Development构建通过。30/60/120Hz分别331/661/1321帧，持续前走、80–220ms短输入、停步中重新前进均覆盖；求解失败0，没有靠冻结上一帧通过检查。
- 实际原生组件的肢段长度与机匣相对双腕误差均小于0.000001cm；显示模型与胶囊水平偏移0，单向测试无负向拉回。
- 靴底最低约0.02cm，较低一只脚的最大离地0.69cm，高度修正最多2.24cm。腕部弯折约14.6–31.0°。这些是本测试范围数据，不代表全部动作美术通过。
- 60Hz检查手套、小臂、距肩9cm外的上臂与枪械三角面对变形胸廓凸包，相交0；30/120Hz重复原生姿态、蒙皮顶点和接触检查，未冒称也做全三角面检查。肩部连接区及其他全身自交不由本项自动验收。
- 源图实际FeetState锁定期踝骨水平残余峰值6.8–8.4cm/s，不能宣称严格零脚滑。记录的是实际锁定状态；原动画FootLock曲线会在移动时被源图进一步衰减，不能混为一谈。坡面/地形不在通过范围。
- C++基础适配对旧Python391帧记录：最大位置误差0.0000244cm、旋转0.0000312°。该对照关闭新增肘间隙和鞋底修正，仅证明算法移植一致；不冒称最终新姿态与旧姿态完全相同。
- 14组原生关键帧截图，已查看正侧后及快速起停。实际桌面键鼠检查见上文；用户视觉验收仍待完成。
- 原1252个Fireline资源、726个原ALS文件哈希未变。选定作者、第一人称、默认基线参数、正式0.1.10及旧候选保留。
