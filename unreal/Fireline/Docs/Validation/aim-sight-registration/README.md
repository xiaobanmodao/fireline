## 已否决的两轮方法

1. **整组握持挂点 + 胸/锁骨/头颈配准。** 保持双手和枪的原相对接触、肢段长度，先把虚拟眼点对到机瞄轴。原生19组30 Hz记录共2311帧：点位对齐成功，但右腕最大65.11°、手臂最小可达余量仅0.060 cm；枪与胸部包络最大侵入约5.31 cm。因而否决。
2. **加入表面和腕部限制的离线复核。** 从已有60 Hz记录抽取37个姿态，加入胸/头盔包络约束重新评估。求解器报告收敛，但眼线最大误差5.15 cm、右腕53.49°，未限幅的颈部目标修正50.43°。仍失败；没有继续构建/发布这组参数。

第二轮后停止该参数拟合方法，恢复原有姿态实现。没有只凭一张正面图交付，也没有因求解器收敛而认定成功。
