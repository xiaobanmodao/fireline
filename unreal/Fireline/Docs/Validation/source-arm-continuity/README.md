# 全动作诊断与接触连续性 — 2026-09-27

## 当前结论

用户要求彻底修正人物动作，并参考成熟作品。这一目标 **尚未全部达到**。本轮按最终蒙皮、运行时逐层骨骼、功能回归三条证据检查；未采用或发布已失败的肘部改写。仅保留经过后续验证的 MP7 接触修正连续性及动作结束恢复路径。M4 上轮持枪层归属修正保留，本轮没有更换其肩臂体态。

## 来源与适用边界

- [Epic Lyra 动画结构](https://dev.epicgames.com/documentation/en-us/unreal-engine/animation-in-lyra-sample-game-in-unreal-engine)：全身移动、按骨骼分层、武器专属动画层，使用状态与调试工具追踪最终输出。
- [Epic 动画适配说明](https://www.unrealengine.com/tech-blog/adapting-lyra-animation-to-your-ue5-game)：适配动画要同时考虑骨架、状态与退出条件，不能只替换片段。
- 继续使用已有 MoCap Online / Lyra 原始姿势研究；新增直接读取安装在本机的 Epic 持枪、切枪、换弹和起跳/空中/落地六段原件，禁用抽样重定向，共525个样本。路径、SHA256及测量范围见 native-reference.json。原始位置数据保存在 Saved/NativeRifleReference，不公开再分发。

这些材料是制作依据，不是“已经复刻 Apex”的证据。本轮没有训练机器学习模型，也没有把第一人称的肘部数据冒充全身动作。

## 已复现的原因

1. MP7 身体适配的公共枪手组合修正可在相邻帧选择另一个解。已有输入动画平滑，但最终起跳中曾出现约19.23 cm单帧位置变化。
2. MP7 Draw/Inspect 自然结束时直接把片段索引和权重清零，没有使用已经存在的恢复路径。输入打断已有恢复，自然结束却没有。
3. 第一人称构图的肘部不能直接作为第三人称肘部目标。将其作为提示后，固定骨长、接触正确仍可能侵入躯干。
4. 平滑绝对手位置会拖慢动作本身，给换弹引入腕部折弯。需要区分作者动画与额外适配修正。
5. M4 的 BodyPose 后还有 ContactCarry；MP7 没有同一最终持枪层。两者不能无条件共用新的时间约束。

## 保留的实现

开关 FirelineContinuousContactStudy：

- MP7 全身适配保留上一帧胸部空间中的 **修正向量**，对额外修正连续求解，原片的手部运动仍按原有时间播放。零时间刷新不重复推进已建立的历史。
- M4、刀具不进入这项新求解；原始模型、绑定、蒙皮、手指、动作文件均未修改。
- MP7 自然结束保留末帧，进入已有0.12秒恢复路径。输入锁定仍按原有ready规则解除；没有延后弹匣入座、开火或开镜。

这里的连续求解是本项目工程实现，不声称是直接复制 Lyra 的算法。

## 不采用的尝试

- SourceArmCandidate / Candidate2：使用第一人称动作肘部提示及约束弧。检查发现新增躯干侵入；未保留在运行代码。
- ContinuousContact：限制绝对腕位置，运动跳变下降，但M4操作回归3个姿势失败；未发布。
- FeasibleContact：收紧腕部优先级，部分腕角改善，但MP7换弹出现新的接触问题；未发布。
- Correction / StateContact：排查修正空间和动作层交接。M4不适用通用修正；重置MP7历史又会增加交接跳变。失败输出、日志与实现补丁保留在本机Saved目录。

同一肘部提示方案两轮失败后已停止，不继续叠加角度偏移。

## 测试解释

- 40组固定输入包含方向移动、起停/反向、切换、操作、跳跃。52秒完整动作诊断包含两枪换弹、俯仰、蹲伏、滑铲以及刀具检视。截图为原生运行采样，不覆盖全部可能输入。
- 分层分析区分原片改编输入、BodyPose输出和最终输出；输入层不是原始供体。
- 连续步长统计排除了不同武器网格切换帧，避免把不同骨架在同名骨骼上的位置变化误判为同一片段抽动。
- 旧MP7检查把第三人称肘部当作第一人称片段坐标比较；关闭本轮开关的原基线也有567个此类失败。修正测试后：第一人称继续比较原片，第三人称验证枪体空间内的手和机械零件接触；该测试不再冒称验证第三人称肘部外观。
- 原资源清单1252项重新校验，0缺失／0变化。构建和测试日志在Saved。

## 最终保留版本的实测结果

- 构建成功；M4操作回归33项、1341个姿势样本通过。M4新接触修正已撤出，原持枪／操作求解不受该开关影响。
- MP7最终操作回归通过；具体计数见Saved/final-contact-mp7.log。测试定义的修正和原基线失败已记录于上文，未把体态验收藏进接触断言。
- 40组比较：MP7地面组最大相邻帧腕／肘位置变化14.49→9.40 cm；跳跃组19.23→6.56 cm；操作组18.47→12.94 cm。不同骨架切换帧不纳入这个连续性统计；快速作者动作本来也会有位移，这些最大值不等于每一项都是抽搐。
- 两次完整动作各6122个左右臂样本，肩部连接、双手与枪接触及前臂辅助骨误差记录为零。极端俯仰的最大腕夹角仍约65.17°，没有声称已经修好；该角也不能单独作为解剖学诊断。
- 完整操作的旧圆柱代理最大侵入0.1255→0.0889 cm；不是三角形级零穿模证明。40组移动中该中间层代理值为零。
- 最终数据见final-movement-comparison.json和final-actions.json；对应本机Saved/MP7CorrectionMovementFinal、MP7CorrectionActions。
- MP7CorrectionMovement首次采集被菜单暂停并提前退出，没有完整CSV，已判为无效。补充自动方向检查的真实按键隔离，复跑得到Final数据；脚本现在会拒绝把缺少CSV的正常退出视作成功。

## 未完成的事项

完整第三人称体态、极端俯仰、部分换弹肩臂配合与护甲表面接触仍待修正；不宣称零穿模或全套动作已合格。已有无限高椭圆柱的躯干代理只能发现部分风险，不能代替实际网格接触检查。

下一次整体姿态改写必须以真实全身持枪片段为基础：原件→仅重定向→接触修正→运行时四层同屏对照，先保留整个肩臂链，再适配枪械握点。不得再把第一人称肘部或一条固定方向当作完整第三人称动作；源动作事件也要和弹匣插入／释放同步后才进入游戏。
