## 本轮确认的问题

从原生最终姿态、实际蒙皮顶点和四面渲染对照发现：强行把当前虚拟眼点压到机瞄线上，会让头盔右侧下颌/侧面外壳与枪托、机匣相交；继续靠低头、侧倾补偿，会产生明显不自然的头颈姿态。这个结论针对本轮具体姿态，不证明该模型永远无法使用机瞄。

Ryan 没有眼球骨。绑定空间 `[-3.2,16,190] cm` 是此前选取的面罩内设计代理，**不是测得的真实眼点**。腕角、视线和姿态阈值也只是项目筛查门槛，不是人体解剖标准。枪械照门/准星辅助点与实际模型相邻表面高度约差0.63 cm，未发现足以解释整个错位的枪械标记偏移。

另一个具体错误是检测采样：最初仅保留枪械分部凸包的349个极点，漏掉了机匣/枪托凹处的实际表面。因此，最初看似满足包络条件的静止姿态仍有真实穿插。后续改为按蒙皮所属部件保留5618个不同位置，再对实际渲染三角形做面面对撞。今后不得以分部凸包顶点通过来宣称整把枪通过。

## 实际表面复核

三角面相交检测使用AABB粗筛与三角形分离轴检测，包含接触、处理共面；投影容差为 `1e-6 cm`。它检测表面交叉，不检测一个闭合物体完全包含另一个物体。选取至少一个顶点主权重属于 Head/Neck 的340个面，逐一与10702个枪械面比较；三个姿态均无退化三角形被排除。

| `static-constrained` | 322 | 17 | 原稀疏采样漏检，否决 |

## 运行时试验及边界

参照本机保留的 ALS Refactored `b754d6f` 完整 Rifle 图与 Epic 的上半身层设计。本轮分别试验源姿态上的修正叠加、完整上半身姿态的瞄准混合。文档依据见 [Epic 分层动画](https://dev.epicgames.com/documentation/unreal-engine/using-layered-animations-in-unreal-engine)、[Aim Offset](https://dev.epicgames.com/documentation/unreal-engine/aim-offset-in-unreal-engine)。这不是复制某款游戏的内部实现，也不表示本轮姿态本身来自成熟源动画。

修正叠加在运动中会使手臂不可达；固定长度的锁骨补偿只能消除部分静止失败，动态仍有266帧求解失败。完整上半身混合消除了本轮2311帧中的求解失败，并保持手枪共同接触与骨长，但没有解决静止头盔相交；移动过渡仍有329个枪/胸包络相交三角形实例，最大顶点侵入包络约1.62 cm。因此两种试验都已撤回，**零求解失败不代表动作合格**。

最后一轮原生范围：30 Hz、19组、2311帧、38张Metal截图；静止/移动瞄准、打断和俯仰，不包括第一人称、开火或换弹。截图并未全部获得视觉验收；已有失败足以拒绝发布，没有继续扩展120 Hz或后续动作。原始输出位于本机 `Saved/MatureMotionResearch/LiveCarryProject/Saved/LiveAim/contact-pose-dynamic-30/`。
