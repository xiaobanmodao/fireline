## 未接入的静止诊断

1. 只修横截面仍穿插。先前离线“feasible”标签的Neck到Head向量相对竖直方向近60°；旧31.5°只是追加改动量，漏掉原姿态，不能当成合理颈部。
2. 地标/轮廓修订后，纯抬枪或扩大转头仍失败。不能继续靠缩窄颈部或全局系数拟合掩盖接触冲突。
3. 按真实肩部表面及固定长度肩臂链构造的另一个单帧，在当时轮廓下头颈/胸肩与枪械表面相交为0；但手臂/躯干仍有15对非相邻面相交，因此**整体拒绝**。最终网格复核的交叉集中在左上臂/胸肩9对、右上臂/胸肩6对；15对均跨越双方三角平面，不是仅因容差统计的擦边接触。肩—上臂—小臂实际端点与蒙皮骨轴一致，骨段长度保留；这些数值成立仍不能代替肩臂表面接触成立。
4. 该诊断对后侧113个枪托面与肩面测距：顶点到面给出1.7325cm的上界；补充全部内部边到边候选后，最近距离约0.4804cm。早期“至少1.7cm”表述错误，已纠正。这只是选定面集的最小距离，不证明枪托贴肩面积/法线、受力关系成立。最终衣领修订又改变了局部头颈表面，未把旧诊断的眼线声明沿用为最终验收。

这些诊断从未写入运行时姿态或动画资源。当前入口仍播放原Presentation姿态；第3阶段换弹保持未完成。
