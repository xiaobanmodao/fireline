# M4 移动与瞄准修订（2026-09-28）

当前是独立的第三人称 M4 平地动作候选；不将这一轮的几何检查当作「Apex级」或所有动作的美术验收。默认游戏、第一人称、原版模型/动作文件和正式0.1.10保持原样。旧的起停、多方向和准备/瞄准入口仍可运行。

## 体验

访达双击桌面「火力对决／**测试版·M4移动瞄准修正.app**」。实际入口 `/Users/hht/UnrealBuilds/Fireline/Launchers/FirelinePresentationStudy.app`，运行 `-LiveCarryAimStudy -LiveCarryPresentationStudy`。它共享独立测试工程，不是冻结的历史二进制。

- WASD移动，Shift慢跑；右键按住瞄准，也可以按F保持/取消瞄准。
- ↑/↓俯仰，Q/E改变身体朝向；鼠标自由环绕，1–4切换四面。
- 6启动/停止77秒自动演示：八方向、走跑转瞄准、反复打断、连续侧移、后退俯仰、快速反向与转身；R回到起点。
- 5切换ALS参考人物。这里保留原姿势/状态规则，但本进程的瞄准过渡时间已经适配，不能声称这个按钮展示完全未改动的原版时间曲线。未修改的源图仍可在旧准备/瞄准入口对照。

先检查正常速度下的起停、跑转瞄、左右反向，再从侧面观察枪托是否离肩、双手是否脱离枪、肘部是否跳动。

## 查到的问题与处理

1. **瞄准时枪托漂移。** 旧实现锁了准星方向，位置却仍跟随源右腕。对旧3421帧实际蒙皮骨架记录测得完整瞄准时，枪托相对肩部的挂点漂移最大5.776厘米。现在用实际M4枪托后垫顶点的中心建立支点，完整瞄准围绕肩部挂点转动；手和所有枪械部件仍是共同组件。支点来自原静止瞄准帧，不是重新猜一个握持偏移。头部眼点/精确贴腮不包含在这个指标内。
2. **跑转瞄过急。** 原ALS瞄准入口使用0.2秒自定义曲线，退出使用1秒自定义曲线；当前M4握持与杠杆长度不同，叠加注册后放大了举枪位移。仅在新测试进程中，把原Rifle状态机相关过渡适配为0.24秒Cubic，保留状态条件、原始姿势库、连续图实例和腿部相位。不是分别滤波手腕，也没有延迟鼠标输入或改游戏射击响应。旧14组同条件下左腕峰值735→535厘米/秒、左肘573→344厘米/秒；下降不等于没有任何观感问题。
3. **支撑脚仍滑动。** 旧最终脚骨在源锁定阶段最大27.13厘米/秒。对照原源骨也有27.60厘米/秒，不能把全部误差归咎于重定向；新比例注册在转身时另有约4.89厘米/秒的偏移变化。现在按原ALS最终LockAmount捕获目标人物自己的世界坐标接触点，释放沿原权重退出；落脚曲线不冒充已锁定状态。不重建方向步伐，不强制摆动脚落地，不伸长骨骼。
4. **方向键首帧重复输入。** 原按下事件先加一次移动输入，同一帧轮询又加一次，斜向刚起步可能偏向先按的方向。新入口只保留一次归一化轮询；旧入口逻辑保留。
5. **参考道具残影。** 实际侧面瞄准时，人物腰部后方出现悬空黑色枪械局部。它不在目标body/gun导出的该区域顶点内；隐藏源角色时未处理独立附着道具。隐藏/显示参照角色现在递归处理其附着Actor，原生侧面窗口复查残影消失。

## 验证与失败记录

`presentation-stress-30/60/120` 分别2311、4621、9241帧，共16173帧。19种组合均记录实际最终骨骼并执行完整候选臂/枪三角形对胸部包络裁剪：0无效姿态、0所测胸部相交三角面，握持与肢段长度误差<0.002厘米，完整瞄准准星方向误差<0.1度，原生锁脚阶段水平速度<0.001厘米/秒。腕部最大44.5度是现有项目约束，并非人体通用标准。60Hz为Metal窗口捕获38帧图，30/120为NullRHI；另用可操作窗口的F/6检查实际时间播放。

第一次仅加入枪托挂点和锁脚的实验，仍使用旧自定义瞄准过渡：15个枪械三角形在短暂过渡中与胸部相交，且抬枪峰值反而增大；没有发布该实验。`failed-mount-with-old-transition.json`保留失败。重新检查状态机入口曲线后才修改整链过渡，随后通过上述扩展回归；没有反复试挪手腕。

1252个既有游戏资源校验无缺失/改写。最后的道具可见性修复不写骨骼或变换，另外进行原生侧面瞄准复查。

## 尚不能声称完成

- 面罩眼点、精确贴腮和肩窝的美术接触尚未验收；稳定支点不等于完全正确的眼—机瞄关系。
- 检测胸部凸包不等于检测所有肩甲、手指、衣物表面的任意碰撞。
- 锁定阶段无滑动，不等于整个步态支撑期、所有坡面都零脚滑。
- 此入口未接开火、换弹、第一人称ADS、蹲跳滑铲及其他武器，不代表完整FPS动作已经达到Apex水平。
