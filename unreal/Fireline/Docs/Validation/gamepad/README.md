# 手柄适配（2026-09-26）

入口：桌面「火力对决」→「测试版·手柄适配.app」。沿用原片起停候选；正式 0.1.10 保留。此入口是本机 UE 原生启动器，不是网页。

## 控制

| 操作 | Xbox / PlayStation |
|---|---|
| 移动 / 视角 | 左 / 右摇杆 |
| 瞄准 / 开火或近战 | LT / L2、RT / R2 |
| 跳跃 | A / × |
| 按住蹲伏；奔跑时滑铲 | B / ○ |
| 换弹 | X / □ |
| 下一武器 | Y / △，或 RB / R1 |
| 上一武器 | LB / L1 |
| 切换冲刺（停下取消） | 按下左摇杆 |
| 切刀 | 按下右摇杆 |
| 检视 / 空手测试 | 十字键上 / 下，沿用现有各武器动作支持 |
| 第三人称观察 | View / Share |
| 暂停 | Menu / Options |
| 菜单导航、确认、返回 | 方向键、A / ×、B / ○ |

设置 → 手柄：转向速度、开镜倍率、移动/视角死区、垂直反转；应用后持久保存。默认 240°/秒水平速度、0.45 开镜倍率、移动死区 0.15、视角死区 0.12。垂直速度为水平的 0.75。右摇杆采用 1.6 次曲线帮助小幅瞄准。

## 实现边界

读取 UE 原始摇杆值后做一次径向死区，避免引擎逐轴死区再次加工。移动保留模拟幅度；视角以帧时间积分，不复用鼠标灵敏度或 GCMouse 增量。扳机具有按下/松开迟滞。暂停、失焦、断连清除手柄持有状态，需释放动作按键/扳机后重新接收。武器动作仍走既有射击、换弹、切换方法，保留插匣补弹和开火中断。

没有替换模型、骨架、动画资产。本轮不包含辅助瞄准、震动、自定义键位；依赖 UE/操作系统识别的标准手柄。尚无真实手柄或 Windows 硬件验收，自动注入输入不能证明蓝牙连接、实际死区手感或驱动兼容性。

## 验证

见同目录保存的检查日志与截图。模拟输入检查覆盖径向死区、模拟移动、角速度、扳机、跳跃、蹲伏、换弹打断、切换请求、暂停清理及菜单焦点；设置检查使用临时偏好文件，不覆盖用户偏好。失败的初版检查日志保留以说明时序和焦点修正过程。

最终结果：原生 Development 编译通过；`gamepad-audit.log` 为 29 检查、0 失败；`menu-audit.log` 保存和恢复偏好、主菜单/训练/暂停循环通过；`mouse-audit.log` 的 360 帧 GCMouse 注入回归最大角度误差 0.00000001°。`settings.png` 为本轮实际运行截图，已查看。初始测试假定固定 60 FPS，但实际运行约 120 FPS；已改为按实测帧时间累计期望角度、验证一次持续扳机产生多发子弹，不能将模拟角速度公式验证描述为多台硬件实测。
