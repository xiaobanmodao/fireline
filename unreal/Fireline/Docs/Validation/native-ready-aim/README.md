## 数据依据与改动

- 读取已下载 Ryan `Character.blend` 的完整37骨骼、原作者 HoldRifle/AimRifle控制。`RifleIK` 的方向在两状态之间基本一致，控制位移约[-9.801,-3.123,-4.029]cm。旧手腕旋转推算额外转动了枪身，本次取消这种推算。M4方向与已有握持一起注册，不单独挪左/右手。
- 原模型肩宽49.51cm，当前派生骨架39.18cm。只用测量比例适配胸部空间横向控制行程，不猜全局偏移或改变臂长。
- 原作者低锁骨Hold姿态仍会使上臂碰胸甲；端点仅按肩宽缩放也失败。保留已通过AimRifle的锁骨位置，完整肩臂分支共同注册，再跟随原控制行程。**这是适配候选，不是未经修改的原片FK。**
- 左肘面避让修正约26.85°→6.46°，右肘约9.35°→25.73°，均未放宽既有30°范围。先解最近的实际表面脱离角，再检查该解腕角；不能因30°终点腕角超界，误判较小的可行解也失败。
- 普通持枪保持原作者准备时的直立头部方向。抬枪使用实际ALS Aiming帧90的头部变形旋转，保留native头位置/颈部及原头盔形状。这不是完整ALS头颈重定向，也不代表眼线已对齐。
- 65段控制采样生成连续路径。原ALS Rifle状态机的Aiming权重及会话内0.24秒Cubic过渡控制播放。先native局部FK插值保持骨长，再用连续肘平面、固定长度重建极小的采样间误差；整套native DJ/M4接触保持刚性。没有肩/肘/手腕层叠的多个写入者。

没有新导入网格、修改蒙皮、缩放头盔、修改native131参考骨骼或手指权重。沿用上一轮ChestPanelStudy重量修正。
