# M4 右臂穿入躯干修复 — 2026-09-27

用户定位：M4 正常持枪／移动。全部由主智能体执行，未使用子智能体。

## 原因与修改

BodyPose 后还会执行 ContactCarry，它从原片极向与腕部约束重新求肘位置，但没有躯干外侧约束，因此可把右肘带回肋部。静止实际世界坐标中右肩 y=22.791cm，右肘 y=14.432cm，上臂在画面中埋入身体。

只在既有 StockContact 的 M4 最终 ContactCarry 求解中，沿相同固定臂长的肘圆选择位于右肩外侧平面的弯曲方向，同时约束腕弯曲并保留已有极向连续限制。没有移动肩关节、双手或枪械；没有启用 SourceBody / CombatGround，没有修改模型与蒙皮。
