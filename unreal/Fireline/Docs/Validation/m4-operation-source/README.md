## 定位结果

1. **原片没有伸长骨头。** 当前派生左臂两段为29.2624／29.3553厘米，右臂为29.2624／28.1329厘米；原片相同段长保持正常。右手相对枪体的位置最大变化不到0.0007厘米。问题不是原片在掏匣时随意拉伸骨骼或松开右手。
2. **第一人称动作与全身持枪配准不能直接合用。** 两种换弹第32帧（作者时间0.5333秒）左腕距枪体骨原点约78.43厘米。这个数不是“手臂长78厘米”，也不能单独证明动作非法；它表明掏匣路径有很大的离枪移动。将该路径套进当前全身携枪配准后，134个动作采样里左腕目标最坏超出目标臂长13.416厘米。详见 [端点可达性记录](reach-diagnosis.json)。
3. **完整运行输出否决了直接接入。** 同样8组举枪／静止换弹／多方向移动换弹／中途取消输入，直接移植1981帧中285帧求解失败；不叠加动作的对照为0。失败检查会保留上一有效姿态，因此不能把它当可交付动画，冻结姿态更不能当作修复。
4. **全局平移／旋转也被否决。** 在134个采样上尝试一个共同操作配准、保持手枪关系。优化器虽正常退出，但腕弯仍达左68°／右51°，端点仍不可达，近似胸部凸包穿入达7.54厘米。`success: true`仅表示优化终止，不是动画通过。没有采用这个结果。

以上是诊断证据，非最终美术验收。第二次只是离线拟合，没有发布它的效果、也没有完整播放验收。

- 从已下载的Lyra全身换弹检查骨盆—脊柱—肩—肘—腕完整关系。现有研究采样只提取了部分上身骨骼，不能冒充完整全身重定向结果；先补齐原片骨架/层级/实际参考矩阵，再做原片与目标的独立对照。
